# jarvis-ai-assistant
An advanced AI desktop assistant built using Python and Ollama.

## 🚀 Features
- Voice Commands
- Face Authentication
- Desktop Automation
- AI Chatbot
- Open Applications
- Smart Responses

## 🛠 Technologies
- Python
- OpenCV
- Ollama
- SpeechRecognition
- Pyttsx3
- Eel

## ▶ Run Project

```bash
pip install -r requirements.txt
python main.py
```
